# TD — Modularisation en langage C

![CI](https://github.com/adell2024/td-modularisation-c/actions/workflows/ci.yml/badge.svg)

Projet pédagogique illustrant la modularisation d'une application C :
abstraction du littéral, factorisation de code, masquage d'implémentation
et compilation séparée.

## Compilation

    make

## Exécution

    ./symboles 3

## Nettoyage

    make clean
